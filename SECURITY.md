# Security policy

## Scope

This repository contains documentation, Mermaid sources, generated SVG previews, and automation configuration. It does not operate a banking service or process live customer transactions.

Report vulnerabilities that could expose secrets, execute untrusted content, compromise the repository or CI workflow, or create a security risk in the rendered artifacts.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability-reporting flow from the repository's **Security** tab when it is available. If private reporting is not enabled, contact the repository owner through their GitHub profile first to arrange a private channel. Include a clear description, affected path or workflow, reproduction steps, and any suggested mitigation. Do not include secrets or personal data in the initial report.

## Handling reports

The maintainer will assess the report privately, coordinate a fix where appropriate, and decide when disclosure is safe. Public discussion is welcome only after the issue is resolved or the maintainer confirms it is safe.
