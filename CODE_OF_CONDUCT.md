# Code of conduct

This project aims to be a respectful, constructive space for discussing process design.

## Expected behaviour

- Be professional, specific, and respectful when challenging a model or process.
- Focus feedback on diagrams, sources, assumptions, and implementation—not people.
- Protect confidential, customer, and security-sensitive information.
- Welcome different domains, jurisdictions, and professional perspectives.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, publishing private information, or knowingly sharing confidential material are not acceptable.

## Reporting

For conduct concerns, contact the repository owner privately through their GitHub profile. For security concerns, follow [SECURITY.md](SECURITY.md). The maintainer may remove content or participation that conflicts with these standards.
